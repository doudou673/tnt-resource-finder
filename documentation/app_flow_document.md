# App Flow Document for TNT Resource Finder

## Onboarding and Sign-In/Sign-Up

A new user starts by visiting the landing page of the TNT Resource Finder. This page welcomes the visitor with an introduction to the purpose of the site and offers two clear buttons to either sign in or sign up. When the user chooses to sign up, they see a simple form requesting their email address, password, and a confirmation of the password. After filling out these fields, the user clicks “Create Account,” and the app validates their input through the Better Auth service. If the email is already in use or the passwords do not match, an inline message explains the issue so the user can correct it. Once the account is created, the user is automatically signed in and redirected to the dashboard. If the user already has an account, they tap “Sign In” and supply their email and password. Upon successful authentication, the user lands on the dashboard. A “Forgot Password” link is provided on the sign-in form. Clicking this link prompts the user to enter their email address. The app sends a password reset email, and the user follows a link from their inbox to set a new password. After resetting the password, they return to the sign-in form to log in with the new credentials. To sign out at any time, the user clicks the “Sign Out” button in the header, which ends the session and returns them to the landing page.

## Main Dashboard or Home Page

After signing in, the user arrives at the main dashboard located at `/dashboard`. The top of the page features a header with the TNT logo on the left, the user’s name and role on the right, and a “Sign Out” button. On the left side of the screen, there is a collapsible sidebar with navigation links labeled “Search Resources,” “My Favorites,” and, for administrators, “Admin Panel.” The central area of the dashboard shows the search interface by default. It includes an input field to enter a member or event name, a dropdown to filter by resource type, and a “Search” button. Below this search bar is a data table that will display results once the user performs a search. Each row in the table shows the resource title, the associated member, the event name, the resource type, and a link icon to view the resource. At the bottom of the page, a footer displays version information and a link to the help center.

## Detailed Feature Flows and Page Transitions

When the user enters a query in the search input and clicks “Search,” the dashboard sends a request to the `/api/search` endpoint. The API route reads the query parameter and uses Drizzle ORM to look up resources in the PostgreSQL database, filtering by member name, event title, and resource type if specified. The server returns a JSON array of matching resources. The dashboard receives this data and re-renders the data table with the new rows. If the user clicks the link icon in a row, the app opens the resource URL in a new browser tab. If the user wants to save a resource for later, they click a star icon next to the row. The app then sends a request to `/api/favorites` to add or remove that resource from their personal favorites list. When the user selects “My Favorites” in the sidebar, the dashboard replaces the search interface with a table of favorited resources, retrieved from the `/api/favorites` endpoint. Users can remove items from this list by clicking the star icon again. Administrators have access to the “Admin Panel” link in the sidebar. Clicking it navigates to `/dashboard/admin`. This page displays a table of all resources in the database with an additional “Actions” column. Admins can click “Add Resource,” which opens a form where they enter the title, URL, choose a resource type, select a member and an event from dropdowns populated by `/api/members` and `/api/events`. After submitting, the app posts the new entry to `/api/resources`, and upon success the user returns to the admin list with the updated table. To edit an existing resource, the admin clicks an “Edit” button in the Actions column. This pre-fills the form with the current values. After saving changes, the list refreshes. An admin can delete a resource by clicking a “Delete” button and confirming the action in a modal dialog.

## Settings and Account Management

Users can update their account details by clicking their name in the header to open a dropdown menu. From there, they select “Profile Settings.” The settings page shows their email address (non-editable) and allows them to update their display name and password. To change the password, the user types the current password, then the new password twice. They click “Save Changes,” and the app calls `/api/account/update` to apply updates. A confirmation message appears upon success. If the user navigates away from this page without saving, unsaved changes are highlighted with a warning prompt. From the Settings page, a clear link titled “Back to Dashboard” brings the user to the main view.

## Error States and Alternate Paths

If the user enters invalid credentials during sign up or sign in, the form displays a red error message next to the relevant field explaining what went wrong. During password reset, if the provided email is not recognized, the app shows a message saying the email was not found. When performing a search, if the network connection is lost the table area shows a banner reading “Unable to connect. Please check your internet connection.” If a query returns no results, the data table area displays the message “No resources found for your search.” On the admin panel, if saving, editing, or deleting a resource fails due to a server error, a modal alerts the admin with the error details and offers a “Retry” button. If the user tries to access the admin panel without administrator privileges, they are redirected to the main dashboard and see a notification stating “You do not have permission to view that page.”

## Conclusion and Overall App Journey

From the moment a new visitor lands on the TNT Resource Finder, they are guided smoothly through creating an account and signing in. After entering the dashboard, regular users can search for resources by member or event, filter and sort results, mark favorites, and view any resource directly with a single click. Administrators enjoy an additional path to manage the resource database through a protected panel that supports creating, updating, and removing entries. Account settings are easy to access for updating personal details or changing passwords. Throughout the experience, clear error messages and fallback pages ensure that users can recover gracefully from mistakes or connectivity issues. This flow empowers teens, educators, and administrators alike to discover, manage, and share valuable media resources efficiently.
